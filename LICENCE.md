## 🧩 About

**World of Warcraft Unlocker Client** is a curated list of World of Warcraft open-source tools:

- **Overlays** — on-screen helpers, layout notes, coordinate viewer, map markers
- **Quality-of-Life Helpers** — loot tracker, inventory notes, overlay notes
- **Research Notes** — UI layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Coordinate Viewer — display current position and zone info
- Map Markers — add custom waypoints for study
- Loot Tracker — record and review loot drops
- Overlay Notes — keep notes on screen during play

### Wallhack
- Transmog Catalog — browse cosmetic appearances
- Mount & Pet Notes — organize collected companions
- UI Skins — custom interface layouts for clarity

### Aimbot
- Rotation Notes — study ability sequences
- Cooldown Tracker — monitor important timers
- Combat Log Viewer — review damage and healing events
